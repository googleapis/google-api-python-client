getUserQuota(name, x__xgafv=None) 
Retrieves the review quota limits and sliding-window usage for the authenticated caller.

Args:
  name: string, Required. The resource name of the singleton user quota to retrieve. Format: `userQuota` (required)
  x__xgafv: string, V1 error format.
    Allowed values
      1 - v1 error format
      2 - v2 error format

Returns:
  An object of the form:

    { # Singleton resource representing the authenticated caller's review quota limits and sliding-window usage.
  "customLimitEnabled": True or False, # Output only. Whether a custom per-user quota override is active for this user.
  "maxReviewCountPerWeek": 42, # Output only. Maximum free-tier reviews allowed per rolling 7-day window.
  "name": "A String", # Identifier. Resource name of the singleton user quota (`userQuota`).
  "nextAvailableTime": "A String", # Output only. Timestamp when the next review quota slot becomes available if `remaining_review_count` is 0; unset when quota is currently available.
  "remainingReviewCount": 42, # Output only. Remaining free-tier reviews available in the current rolling 7-day window (`max(0, max_review_count_per_week - used_review_count)`).
  "usedReviewCount": 42, # Output only. Number of free-tier reviews used in the past 7 days.
}
