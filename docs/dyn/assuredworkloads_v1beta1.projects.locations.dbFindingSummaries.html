list(parent, filter=None, pageSize=None, pageToken=None, x__xgafv=None) 
Lists summaries of the active findings in a Data Boundary scope (an organization, folder, or project), with one summary for each finding category.

Args:
  parent: string, Required. The parent scope to list finding summaries for. Formats: * `organizations/{organization}/locations/{location}` * `folders/{folder}/locations/{location}` * `projects/{project}/locations/{location}` (required)
  filter: string, Optional. A filter expression that restricts the framework deployments whose findings are summarized. The syntax follows [AIP-160](https://google.aip.dev/160). Supported fields are `framework_deployment`, `framework_name`, and `framework_revision` (the major revision ID of the framework).
  pageSize: integer, Optional. The requested page size. The server might return fewer items than requested. If unspecified, the server picks an appropriate default.
  pageToken: string, Optional. A token that identifies the page of results that the server should return. Pass the `next_page_token` value from a previous result.
  x__xgafv: string, V1 error format.
    Allowed values
      1 - v1 error format
      2 - v2 error format

Returns:
  An object of the form:

    { # The response message for ListDbFindingSummaries.
  "dbFindingSummaries": [ # The list of finding summaries, one for each finding category.
    { # A summary of the active findings for a finding category in a Data Boundary scope.
      "findingCategory": "A String", # Output only. The category of the findings that are summarized.
      "findingClass": "A String", # Output only. The class of the findings.
      "findingCount": "A String", # Output only. The total number of active findings in the category.
      "name": "A String", # Identifier. The resource name of the finding summary.
      "organizationPolicyFindingCount": "A String", # Output only. The number of active organization policy findings in the category.
      "relatedFrameworks": [ # Optional. The display names of the compliance frameworks that the findings are related to.
        "A String",
      ],
      "resourceFindingCount": "A String", # Output only. The number of active resource findings in the category.
      "severity": "A String", # Output only. The severity of the findings.
      "updateTime": "A String", # Output only. The time when the findings in the category were last updated.
    },
  ],
  "nextPageToken": "A String", # Output only. A token that can be sent as `page_token` to retrieve the next page. If this field is empty, there are no subsequent pages.
}
