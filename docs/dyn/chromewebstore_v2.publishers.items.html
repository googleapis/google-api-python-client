fetchReviews(name, filter=None, orderBy=None, pageSize=None, pageToken=None, x__xgafv=None) 
Fetch user reviews for an item.

Args:
  name: string, Required. The item resource name whose reviews are being fetched. Format: publishers/{publisher_id}/items/{item_id} (required)
  filter: string, Optional. A filter to apply to the reviews. Only equality comparison on rating is supported, e.g. `rating = 5`.
  orderBy: string, Optional. An optional comma-separated list of fields by which to sort the results. The default sort order is ascending (`asc`). Supported fields are: - `rating`: Supported orders are `asc` (default) and `desc`. - `create_time`: Only `desc` (most recent first) is supported; `desc` must be explicitly specified since the default is `asc`. Example: `rating desc`, `create_time desc`, or `rating desc, create_time desc`.
  pageSize: integer, Optional. The maximum number of reviews to return. The service may return fewer than this value. If unspecified, at most 50 reviews will be returned. The maximum value is 200; values above 200 will be coerced to 200.
  pageToken: string, Optional. A page token, received from a previous `FetchItemReviews` call. Provide this to retrieve the subsequent page. When paginating, all other parameters provided to `FetchItemReviews` must match the call that provided the page token.
  x__xgafv: string, V1 error format.
    Allowed values
      1 - v1 error format
      2 - v2 error format

      "authorInfo": { # Info on the author of the review. # Info on the author of the review.
