download(name, x__xgafv=None) 
Downloads the original document content (PDF binary) via Scotty media streaming (AIP-136 custom method).

Args:
  name: string, Required. The resource name of the document to download. Format: `documents/{document}` (required)
  x__xgafv: string, V1 error format.
    Allowed values
      1 - v1 error format
      2 - v2 error format
