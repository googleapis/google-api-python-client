Agent Platform API . projects . locations . detectors

Instance Methods

close()

Close httplib2 connections.

create(parent, body=None, detectorId=None, x__xgafv=None)

Creates a new customer-defined Detector. The detector is always created DISABLED; EnableDetector starts it scanning.

delete(name, x__xgafv=None)

Deletes a specific detector. Hard and irreversible: the detector is gone from every read path at once.

disable(name, body=None, x__xgafv=None)

Disables a specific detector, so that it stops scanning. Disabling an already-DISABLED detector succeeds and changes nothing. The detector's config and history survive; only DeleteDetector removes a detector.

enable(name, body=None, x__xgafv=None)

Enables a specific detector, so that it starts scanning. Enabling an already-ACTIVE detector succeeds and changes nothing.

get(name, revisionId=None, x__xgafv=None)

Gets the details of a specific detector, including its current configuration.

list(parent, pageSize=None, pageToken=None, x__xgafv=None)

Lists the detectors in a Location.

listRevisions(name, pageSize=None, pageToken=None, x__xgafv=None)

Lists the revisions of a detector, newest first. Each entry is the detector as configured at one revision, with `revision_id` and `revision_create_time` set. `state` and `selected_revision_id` are unset: neither is a property of a revision, and GetDetector returns both.

listRevisions_next(previous_request, previous_response)

Retrieves the next page of results.

list_next(previous_request, previous_response)

Retrieves the next page of results.

patch(name, body=None, updateMask=None, x__xgafv=None)

Updates an existing detector. A mask covering `custom_detector_config` replaces the whole config; `state` cannot be changed here, use EnableDetector or DisableDetector.
