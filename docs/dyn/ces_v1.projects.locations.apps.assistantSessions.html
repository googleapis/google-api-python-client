cancelAssistantTurn(name, body=None, x__xgafv=None) 
Cancels the assistant session's in-flight turn, if any: the explicit user stop for a turn running detached from any stream. A cancel landing on a task that does not host the turn preempts it through the session turn epoch instead, ending it within one lease renewal.

Args:
  name: string, Required. The assistant session whose in-flight turn to cancel. (required)
  body: object, The request body.
    The object takes the form of:

{ # Request to cancel an assistant session's in-flight turn.
  "turnId": "A String", # Optional. The turn to cancel; empty cancels whichever turn is running. A cancel naming a turn that is no longer the running one is a no-op.
}

  x__xgafv: string, V1 error format.
    Allowed values
      1 - v1 error format
      2 - v2 error format

Returns:
  An object of the form:

    { # Response for CancelAssistantTurn.
  "cancelled": True or False, # Whether an in-flight turn was found and asked to stop (directly on this task, or through an epoch preemption for a turn hosted elsewhere).
}
